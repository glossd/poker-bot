This was an old poker bot for PokerBlow, updated for AI.
This could potentially allow you to run the poker-bot on your behalf with the username and password on PokerGloss.com

Run GeminiAI on your behalf
```shell
make run_ai geminikey=yourGeminiApiKey tableid=67210bf4482003073f320426 email=youremail password=yourpassword
```

Run the old coded algorithm on your behalf
```shell
make run_ai alg=1 tableid=67210bf4482003073f320426 email=youremail password=yourpassword
```
